SHARPE RATIO DEFINITION
────────────────────────────────────────────────────────────────────────────
Sharpe Ratio = (Expected Return - Risk-Free Rate) / Volatility

• Risk-Free Rate = 2% (US Treasury baseline)
• Interpretation: For every 1% of volatility you take, how much extra
                 return do you earn?

HIGHER Sharpe = Better investment (more return per unit of risk)
